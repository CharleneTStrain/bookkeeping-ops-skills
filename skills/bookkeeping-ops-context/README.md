# Bookkeeping ops context

**The problem:** Every bookkeeping question starts with the same background — how the business is set up, which accounts money moves through, what software the books are in, who helps, and what's due when. Answering it every time is tiring, and the answers drift.

**What it does:** Writes your business's bookkeeping picture down once: the business and how it's set up for taxes, accounts and payment processors, software, who does the books and taxes, payroll, contractors, sales tax, and deadlines. Every other skill reads it first. It never stores account numbers, tax ID numbers, or passwords.

**Use it with:** last year's tax return summary, a list of your accounts, a bookkeeper's handoff notes, or just a conversation. "Not sure" is a fine answer.

**You get:** a one-page file at `.agents/bookkeeping-ops-context.md` you can update whenever something changes, and hand to a new bookkeeper on day one.
